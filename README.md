# RAVE Chart V3 · Mockup Style

이번 버전은 사용자가 준 3화면 레퍼런스 느낌에 맞춰 UI를 전면 수정했습니다.

- 홈: 관심종목 현재가 + 등락률 + 미니차트
- 시장지수: 현재가 + 등락률 + 미니차트
- 차트 화면: 큰 현재가, OHLCV, MA5/20/60/120, 거래량, RSI, MACD, 볼린저밴드
- 분석 화면: 0~100 점수, 항목별 분석, 관심/추격주의/손절 구간, RAVE 분석
- 기존 한글/숫자/영문/티커 검색 유지
- 1달 차트 유지
- Netlify Functions 구조 유지

GitHub의 기존 파일을 이 패키지 내용으로 덮어쓴 뒤 Commit changes 하면 됩니다.
