# RAVE Chart FINAL — 한글 검색 앱형

## 핵심
- 한글 종목명 / 영문 종목명 / 티커 검색
- 검색결과에서 회사명 + 티커 + 거래소 표시
- 미국주식 / 한국주식 / ETF 검색
- 실제 일봉 데이터
- 캔들차트
- MA5 / MA20 / MA60 / MA120
- 거래량
- RSI(14)
- MACD / Signal / Histogram
- 볼린저밴드(20,2)
- 100점 기술점수
- 관심구간 / 추격주의 / 추세이탈
- RAVE 자동 한글 분석
- 관심종목 로컬 저장
- iPhone 홈 화면 추가(PWA)

## 배포: Netlify
이 버전은 Netlify Functions용입니다.

1. Netlify 계정을 만듭니다.
2. GitHub 저장소에 이 폴더 전체를 올리고 Netlify에서 해당 저장소를 연결하는 방식이 가장 안정적입니다.
3. 배포가 끝나면 `https://xxxx.netlify.app` 주소가 생깁니다.
4. iPhone Safari에서 열기 → 공유 → 홈 화면에 추가.

※ 단순 Drag & Drop 배포는 정적 파일만 배포되어 Functions가 동작하지 않을 수 있으므로,
   이 버전은 Git 저장소 연결 배포를 권장합니다.

## 데이터
검색과 차트는 Yahoo Finance의 공개 웹 엔드포인트를 서버 함수가 중계합니다.
API 키는 필요하지 않지만, 제공처 정책/엔드포인트 변경 시 향후 수정이 필요할 수 있습니다.

## 투자 주의
기술적 분석 보조 도구이며 투자 권유가 아닙니다.
